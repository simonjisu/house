# 공고 목록과 필터

기본 체크는 **분양·주택 구입, 장기전세, 미리내집·연계형**입니다. 주택 구입을 위한 분양과 매입임대는 별도 옵션입니다. LH 임대·분양 목록을 수집합니다. 청약홈은 별도 API 키 연결이 필요하며 미연결 상태를 표시합니다. 특별공급은 공급 방식이며 자격 확정을 뜻하지 않습니다. 모든 장기 임대를 한 프로그램으로 묶지 않고 국민·영구·통합공공·공공/재개발임대는 추가 체크로 제공합니다. 장기안심은 보증금 지원으로 별도 표시합니다.

유형 체크 다음에는 선택된 유형에 실제 존재하는 세부 구분을 제공합니다. 공고 제목과 공식 목록 유형의 명시적 단어를 사용합니다. 미리내집은 이름에 ‘미리내집’이 있는 공고에만 적용합니다. 도시형생활주택 유형이라도 제목에 매입임대가 있으면 매입임대로 분류합니다. 매입임대Ⅰ/Ⅱ, 든든전세, 청년, 고령자, 다자녀, 공공한옥 등은 명시된 경우만 세부 구분합니다. 분류는 탐색용이며 자격 판정이 아닙니다. 원래 공식 유형과 근거는 각 공고의 펼침 영역에 남습니다.

유효한 목록 마감일을 오름차순으로 표시하고 미확인은 끝에 둡니다. 같은 날짜는 게시일 최신 순입니다. 목록 상태가 마감·종료·취소이거나 한국 날짜 기준으로 마감일이 지난 공고는 기본적으로 숨깁니다. 체크하면 별도 목록에서 볼 수 있습니다. 날짜가 지난 경우에도 공식 접수 종료를 확정하지 않고 원문 상태 재확인 문구를 표시합니다. 마감 당일은 진행 목록에 남기며 접수시각은 원문에서 확인해야 합니다.

SH 목록에 없는 마감일은 제목의 게시일 등으로 추정하지 않습니다. 소득 미확인 공고도 유지하며 현재 검토 완료 공고가 없다는 안내를 유지합니다. 로그인, 열람 허용 목록, RLS, 비밀 키 처리에는 변경이 없습니다.

공고일 기준 최근 7일, 30일, 90일, 그 이전의 네 단계 배경색을 적용합니다. 최근 공고가 더 진하며 텍스트 대비를 유지합니다. 날짜가 없으면 흰색입니다. 색상 범례와 공고일 텍스트를 함께 제공하며 마감일 정렬에는 영향을 주지 않습니다.

청약홈 연결 방법과 특별공급/일반공급 기간 구분은 [API 연결 안내](APPLYHOME_SETUP.ko.md)를 참고하세요. 공급 방식에서 특별공급을 선택하면 확인된 특별공급 기간이 적용됩니다.
